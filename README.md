# Hybride Audio Analyzer - Prototype 0.1

İçerik:
- Mobil arayüz prototipi
- RTA ekran görüntüsü seçme
- Analiz Et akışı
- Örnek HPF / EQ / Q sonuç ekranı
- Android WebView wrapper

Not:
Bu ilk sürüm gerçek AI analizi yapmaz; sonuçlar örnek veridir.
Gerçek sürümde güvenli bir backend üzerinden OpenAI API / görsel analiz bağlanmalıdır.
API anahtarı APK içine gömülmemelidir.

APK üretmek için:
1. Klasörü Android Studio ile açın.
2. Gradle sync tamamlanınca Build > Build APK(s).
